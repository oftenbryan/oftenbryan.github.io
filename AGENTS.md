# Portfolio (oftenbryan.github.io)

Site perso de Bryan : Jekyll + GitHub Pages.

## Commandes

- Aucune commande de build/test/lint configurée (pas de Gemfile, pas de package.json).
- Déploiement : `git push` sur `main`. GitHub Pages compile.
- Preview local (si installé) : `jekyll serve`.

## Handoff Workflow

- Lire `aidocs/HANDOFF.md` en début de session.
- Mettre à jour `aidocs/HANDOFF.md` après chaque gros changement, ajouter une entrée datée dans `aidocs/SESSION_LOG.md`.
- Décisions techniques dans `aidocs/DECISIONS.md`, commandes dans `aidocs/RUNBOOK.md`.
- Ne pas créer de `docs/` : ce dossier est publié par Jekyll.
